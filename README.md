# Bloghub

## 文件库与文件夹

文件库右上角的 ‹ 按钮可向左收起，› 可展开；浏览器会记住收起状态。点击“＋ 文件夹”创建目录，选中目录后新建或导入文件会放入该目录；支持子文件夹与目录展开/收起。点击“根目录”返回顶层。文件名输入框显示相对路径，可修改路径归类；已发布文件换路径后保存会创建新副本，旧文件需在 GitHub 手动处理。

空文件夹保存在浏览器本地，Git 不存储空目录。保存目录内文件到 GitHub 后，目录结构会随文件一起公开到 notes/，其他设备加载公开笔记时自动还原目录树。

## 公开笔记（当前版本）

网站与仓库均公开。编辑自动保存为浏览器草稿；“保存到 GitHub”或 Ctrl+S 将当前笔记提交到 `notes/文件名`，随后 GitHub Actions 自动更新网站公开目录。所有人能读，只有本机 Git 凭据具有该仓库写入权限的人能发布。凭据不进入前端。启动或重启 `python runner.py` 后连接服务即可使用；线上页面如被浏览器阻止访问本机服务，请使用本地网址。

“刷新公开笔记”从已部署网站获取笔记，保留未发布草稿；部署通常需要稍等。发生版本冲突时先下载草稿，再移除本地副本并刷新公开笔记。重命名后发布会创建新文件，不会删除旧文件；公开笔记删除请在 GitHub 仓库处理。先前浏览器草稿不会批量上传，打开需要公开的文件点击保存即可。

以下原版说明中“不会提交到 GitHub”仅适用于自动保存草稿；手动保存按钮现已改为公开提交。

独立编写的原生 HTML/CSS/JavaScript 前端，参考 `D:\code\htmlcase\Bloghub` 的黑色导航、橙色强调色与半透明卡片设计。无第三方模板、无前端依赖、无账号登录。

## 使用

在项目目录运行 `python runner.py`，打开 http://127.0.0.1:8765 。

支持创建、编辑、搜索、删除、导入和下载文本代码/Markdown 文件。修改立即保存至浏览器 localStorage；Ctrl+S 也可保存。基础 Markdown 预览支持标题、列表、粗体、行内代码、围栏代码块，暂不支持完整 GFM、表格、图片、数学公式。原始 HTML 按文本显示，避免执行导入文件中的脚本。

文件仅保存在当前浏览器和当前网站来源中，清理浏览器数据会丢失文件；请下载备份。本地网址和 GitHub Pages 的文件库相互独立，可以导入/下载迁移。保存不会提交到 GitHub，也不会自动公开给其他访客。

## 本地 Python

打开“Python 环境”，粘贴服务启动时终端中的随机密钥，连接后选择环境。可添加 `D:\code\htmlcase\myenv\Scripts\python.exe` 等解释器的完整路径（必须真实存在）。环境列表与密钥随服务重启重置。

打开 `.py` 文件后点击运行，页面确认后执行。服务仅绑定 `127.0.0.1:8765`，验证 Host、网页 Origin 和连接密钥，不对外网开放。密钥仅存于当前页面内存。

代码在临时目录运行，使用所选环境已安装的包；标准输出和错误合并显示。最长执行 30 秒，返回输出最多 200 KB，标准输入关闭，不支持 `input()` 的交互输入。临时目录运行后删除，运行生成的文件不会自动导出。运行代码不是沙箱，拥有当前用户权限，只应运行自己信任的代码。输出先写临时磁盘文件，因此大量输出可能占用磁盘。

## GitHub Pages 部署

1. 新建空 GitHub 仓库（普通仓库名例如 `Blog` 即可）。
2. 将本目录提交到仓库的 `main` 分支。
3. 在仓库 Settings → Pages → Build and deployment 中选择 GitHub Actions。
4. 推送后自动执行仓库自带的 Pages workflow，只上传三个前端文件。

网站地址通常为 `https://用户名.github.io/仓库名/`，所有静态资源均用相对路径。仓库链接和可用的 GitHub 推送权限就绪后可完成实际发布。

若要从线上页面连接本机，启动时允许准确的来源：

```powershell
python runner.py --origin https://你的用户名.github.io
```

Origin 不包括仓库路径、末尾斜杠。浏览器可能要求授予本地网络访问权限，也可能因网络策略阻止 HTTPS 页面连接本地 HTTP。若线上连接被阻止，打开服务提供的本地页面执行 Python；浏览器内编辑、保存、下载不依赖本地服务。别人打开网站只能连接他们自己的本机，无法使用你的 Python 环境。
